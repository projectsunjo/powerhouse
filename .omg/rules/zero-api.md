# Rule: Zero-API Dependency
- 상용 지도 유료 API 키(Google Maps, Naver Maps API, Kakao Maps JS API 키)를 하드코딩하거나 결제 의존성을 만들지 않는다.
- 정적 Leaflet 맵(OpenStreetMap 무료 타일) 및 외부 웹 길찾기 링크(카카오맵 모바일/PC 웹 URL) 방식을 사용한다.
